# Research roadmap

**Claude Code must never train, fit, tune, cross-validate, predict with, or explain (SHAP or similar) any model, and must never run full scientific analysis pipelines or notebooks.** Claude Code prepares code, tests, configs, documentation and commands. The human investigator runs them and returns the outputs for interpretation. This holds in every phase, including phase_04 validation.

Each phase ends at an approval gate. A gate is passed only when the investigator records sign-off in `docs/decision_log.md`.

| Phase | Title | Key deliverables | Approval gate | Status |
|---|---|---|---|---|
| **phase_00** | Architecture and repository standardisation | Directory layout, placeholder package, documentation, manifest and figure-spec templates, CLARIFi provenance, Moringa manuscript linkage, safety hooks with tests, `docs/phase_00_verification.md` | Investigator approves the repository and the pending P00 items | **Awaiting investigator review** |
| **phase_01** | Literature review and dataset feasibility | Literature search protocol and evidence map (`literature-reviewer`, `literature-evidence-map`), including existing approaches to predicting SF2 from molecular data; source inventory; dataset cards and feasibility report (`dataset-feasibility`); cell-line overlap plan; CLARIFi per-record source and assay notes | Primary dataset(s), primary endpoint and cross-dataset/cross-assay scope approved, or a recorded decision to stop or re-scope | Not started |
| **phase_02** | Scientific study design | `docs/protocol.md` (`protocol-first`) covering hypotheses, primary endpoint, inclusion rules, unit of analysis, grouped splits, external validation, prespecified baselines and metrics, missing-data rules, uncertainty, ablations, explainability plan and stopping rules; `docs/protocol_amendments.md` | Protocol frozen and dated (optionally on OSF); statistical, ML and radiobiology review recorded | Not started |
| **phase_03** | ML pipeline development | Loaders, identifier harmonisation, splits and leakage checks, fold-safe features, baseline pipelines, evaluation, plotting functions, unit tests on labelled synthetic fixtures, documented run commands, environment lockfile. Nothing is executed by Claude Code | Code review (`research-code-review`), leakage audit (`leakage-audit`) and reproducibility audit passed | Not started |
| **phase_04** | Investigator-controlled execution and validation | Investigator-run pipeline outputs, run records (commit, config hash, seeds, input and output hashes), result tables, logs | Outputs checked against the protocol; deviations recorded as amendments | Not started |
| **phase_05** | Interpretation, visualisation and manuscript preparation | Figures generated by the investigator from approved scripts; methods (`manuscript-methods`); limitations; a separate, clearly labelled section on the Moringa hypothesis | Statistical and radiobiology review; target journal chosen | Not started |

## Rules that apply across phases

- No phase starts before the previous gate is passed, unless the investigator records an exception.
- Scientific claims need verified primary sources. Proposals are labelled as hypotheses.
- Endpoints are never interchangeable: clonogenic SF2, profiling-derived survival, viability, optical-density or crystal-violet proliferation, and gene expression. The Moringa study's proliferation enhancement factor (PEF) is **not** SF2.
- No claim of selective radioprotection without supporting measurements in both treated normal cells and treated tumour cells.
- The Moringa manuscript is motivation, not training data (`docs/moringa_scientific_linkage.md`).

Open questions for the investigator are tracked in `docs/decision_log.md` (O00.xx).
