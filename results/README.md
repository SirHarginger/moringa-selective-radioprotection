# results/

Analytical outputs of investigator-run analyses (phase_04):
- `tables/`: result tables and manuscript tables (`table_NN_<slug>_vN.csv`);
- `models/`: fitted model artefacts;
- `logs/`: run records.

Contents are gitignored; only this README and the `.gitkeep` files are tracked. Rendered figures do **not** go here; they go to `figures/generated/`.

The prototype folders `results/figures/` and `results/screening/` were retired in phase_00 (`docs/decision_log.md` D00.22).
